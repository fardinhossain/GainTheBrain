# 🛒 ShelfSense AI: Intelligent Retail Merchandising & Stock Auditor

## Category / Domain
CommerceSphere AI (Retail / E-commerce / Inventory Management)

## Date
2026-07-17

## Short Description
ShelfSense AI is a computer-vision-powered platform designed for retail managers and shop floor staff to automate inventory auditing and planogram compliance. By analyzing photos of retail shelves, the AI identifies out-of-stock items, misplaced products, and pricing errors in real-time.

## Problem Statement
Brick-and-mortar retailers lose billions annually due to "out-of-stock" (OOS) scenarios and poor shelf execution. Manual auditing is labor-intensive, slow, and prone to human error. When products are not where they should be (planogram non-compliance), sales drop. Retailers need a fast, objective way to ensure the "digital twin" of their inventory matches the physical reality on the shelves.

## Proposed Solution
A mobile-first application where staff take photos of store aisles. The backend uses advanced computer vision to:
1.  **Identify SKUs:** Match physical products against a reference database.
2.  **Detect Gaps:** Highlight empty spaces that need immediate restocking.
3.  **Verify Compliance:** Compare current shelf layout against the corporate planogram (the ideal layout).
4.  **Price Audit:** Read shelf tags using OCR to ensure they match the system price.

## Target Users
- **Retail Store Managers:** To track daily shelf health and staff performance.
- **Inventory Associates:** To receive automated restock alerts.
- **Brand Manufacturers:** To verify their products are displayed correctly in third-party stores.

## Core Features
- **Mobile Image Capture:** High-resolution photo upload with localized metadata.
- **Object Detection & Classification:** Real-time identification of products and empty shelf space.
- **Planogram Comparison:** Visual overlay of "Ideal vs. Actual" shelf layouts.
- **Real-time Restock Alerts:** Immediate notifications sent to the backroom when high-priority items are OOS.
- **Analytics Dashboard:** Trends in shelf availability and compliance scores over time.

## Advanced Features
- **AR Navigation:** Using Augmented Reality to guide staff directly to the specific shelf gap.
- **Competitor Share-of-Shelf Analysis:** Calculating the percentage of shelf space occupied by the retailer vs. competitors.
- **Predictive Restocking:** Integration with sales data to predict when a shelf will become empty before it happens.
- **Multi-angle Stitching:** Stitching multiple photos of a long aisle into a single panoramic audit view.

## AI/ML Integration
- **Computer Vision:** YOLO (You Only Look Once) or EfficientDet for real-time object detection.
- **OCR (Optical Character Recognition):** Tesseract or Google Vision API for reading price tags and SKU labels.
- **Siamese Networks:** For "Few-Shot Learning" to recognize new product packaging with minimal training data.
- **Anomaly Detection:** To flag items that are in the wrong category or aisle.

## Suggested Tech Stack
- **Frontend:** React Native or Flutter (for cross-platform mobile access).
- **Backend:** Python (FastAPI or Django) for heavy ML processing.
- **AI Frameworks:** PyTorch or TensorFlow, OpenCV for image preprocessing.
- **Database:** PostgreSQL for metadata; Pinecone or Milvus (Vector Database) for product embedding searches.
- **Cloud:** AWS S3 for image storage; AWS Lambda or SageMaker for model inference.

## Database Design
- **Stores Table:** ID, location, manager_id.
- **Products Table:** SKU, name, category, image_embeddings, price.
- **Planograms Table:** store_id, aisle_id, shelf_index, expected_sku_list.
- **Audit_Logs Table:** audit_id, store_id, timestamp, compliance_score, image_url.
- **Detected_Gaps Table:** audit_id, coordinates, timestamp, priority_level.

## API Route Ideas
- `POST /api/v1/audit/upload`: Upload shelf image for processing.
- `GET /api/v1/audit/{id}/results`: Retrieve detection results and compliance score.
- `GET /api/v1/store/{id}/gaps`: List all current out-of-stock items in a store.
- `PUT /api/v1/planogram/update`: Update the master layout for a specific aisle.

## UI Pages
- **Staff Mobile App:** Camera view with AR overlays, task list of restock items.
- **Manager Dashboard:** Heatmap of store compliance, OOS trends, and staff audit frequency.
- **Product Catalog:** Management interface for adding new SKU reference photos.
- **Report Generator:** Exporting weekly shelf-health reports for corporate stakeholders.

## MVP Plan
1.  **Phase 1:** Build a basic image uploader and integrate a pre-trained object detection model for a limited set of 10-20 SKUs.
2.  **Phase 2:** Implement the "Gap Detection" logic to identify empty spaces on shelves.
3.  **Phase 3:** Create the mobile UI for staff to view "Restock Tasks" generated by the AI.
4.  **Phase 4:** Develop the Manager Dashboard with basic analytics.

## Future Scope
- **Robot Integration:** Deploying the software on autonomous floor robots (like Tally) for 24/7 auditing.
- **Consumer App Integration:** Allowing shoppers to see real-time shelf availability via a public app.
- **Supply Chain Triggering:** Automatically placing orders with wholesalers when shelf and backroom stock are both low.
